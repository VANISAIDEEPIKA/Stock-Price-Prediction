# FORECAST FEVER – Stock Price Prediction Using Machine Learning


**FORECAST FEVER** is a web-based **Stock Price Prediction** application developed using **Python, Streamlit, and LSTM (Long Short-Term Memory)** to forecast future stock prices. The application retrieves historical stock market data using the **Yahoo Finance API**, calculates technical indicators such as **Relative Strength Index (RSI)** and **Moving Average Convergence Divergence (MACD)**, and generates future stock price predictions through an interactive dashboard.

Designed with a modular architecture, the system enables users to analyze historical trends, compare multiple stocks, visualize technical indicators, and download forecast reports, making it a practical tool for students, researchers, and investors.

---

## Features

- Real-time historical stock data retrieval using Yahoo Finance API
- Stock price forecasting using LSTM Deep Learning
- Interactive Streamlit web interface
- Technical indicator analysis (RSI & MACD)
- Historical stock data visualization
- Actual vs Predicted price comparison
- Multi-stock comparison
- Future stock price forecasting
- Download forecast results in CSV format
- Modular and scalable application architecture

## Project Workflow

1. User enters the stock ticker, date range, and prediction period.
2. Historical stock data is fetched using the Yahoo Finance API.
3. The dataset is cleaned, normalized, and preprocessed.
4. RSI and MACD technical indicators are calculated.
5. The LSTM model processes the prepared data.
6. Future stock prices are predicted.
7. Historical and predicted prices are visualized.
8. Users can compare multiple stocks.
9. Forecast results can be downloaded as CSV files.
